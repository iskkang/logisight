## 1. 제목 작성 규칙

### 1-1. 글자 수

| 플랫폼 | 제목(Title) 권장 | 메타 디스크립션 권장 |
|---|---|---|
| **구글** | 한글 기준 25~30자 (영문 50~60자) | 한글 70~80자 이내 (영문 155~160자) |
| **네이버 블로그** | 25~35자 (검색 결과에서 약 30자 이후 잘림) | N/A (블로그 포스팅 자체가 스니펫) |

> **실전 팁**: 네이버는 모바일 검색 시 제목이 약 28~30자에서 잘린다. 핵심 키워드는 반드시 앞 15자 이내에 배치해야 노출 효과를 극대화한다.

---

### 1-2. 키워드 위치

**네이버**
- 메인 키워드를 제목의 **앞쪽(첫 번째~세 번째 단어)**에 배치한다.
- 키워드가 뒤에 있어도 완전 배제되지는 않으나, 앞에 있을수록 노출 확률이 유의미하게 높아진다.
- 스마트블록(Smart Block)에서 잡힌 연관 키워드를 제목에 포함하는 것이 2025~2026 기준 유리한 전략이다.

**구글**
- `<title>` 태그 안 핵심 키워드가 **앞부분**에 위치할수록 검색 의도 일치도가 높다고 평가된다.
- 구글은 HTML `<title>` 태그 내용을 80% 이상 검색 결과 제목으로 사용한다. 직접 최적화하는 것이 가장 효과적이다.
- 구분자(`|`, `-`, `:`)로 브랜드명을 제목 끝에 달 수 있다. 예: `주제 키워드 - 브랜드명`

---

### 1-3. 피해야 할 단어 & 패턴

| 피해야 할 것 | 이유 |
|---|---|
| `최고`, `최저`, `무조건`, `100%` 등 과장 표현 | 클릭 유도성 제목(clickbait)으로 판단, 품질 평가 하락 |
| 키워드 중복 나열 | 예: `서울 맛집 서울 식당 서울 음식` → 스팸 신호 |
| 같은 키워드 2회 이상 반복 | 네이버·구글 모두 키워드 스태핑(stuffing)으로 간주 |
| `안녕하세요 오늘은 ~에 대해 알아보겠습니다` | 도입부 클리셰 → 저품질 판정 위험 |
| 특수문자 과다 사용 (`!!!`, `★★★`) | 크롤러가 스팸 패턴으로 인식 |
| 내용과 무관한 인기 검색어 삽입 | 어뷰징으로 직접 제재 대상 |

## 2. 본문 구조

### 2-1. 권장 글 길이

| 플랫폼 | 권장 분량 |
|---|---|
| **네이버 블로그** | **1,500~2,500자** (상위 노출 블로그 평균 수준) |
| **구글 일반 블로그** | 주제에 따라 **1,500~3,000자 이상** (경쟁 상위 페이지 기준 맞추기 권장) |

> 글자 수 자체는 직접 랭킹 요소가 아니다. 2026년 기준 구글은 키워드 밀도·워드카운트를 직접 랭킹 요소로 인정하지 않는다. 중요한 것은 **검색 의도를 완전히 충족하는 밀도 높은 정보량**이다.

---

### 2-2. 도입 - 본론 - 결론 비율

```
도입부   (10~15%) — 검색 의도 확인 + 글의 가치 선언
본론     (70~80%) — 소제목별 정보 전달, 구체적 수치·경험 포함
결론     (10~15%) — 핵심 요약 + 행동 유도(CTA) 또는 관련 글 연결
```

**도입부 원칙**
- 독자의 검색 의도를 첫 2~3문장 안에 확인시켜 준다.
- "이 글에서 X를 알 수 있다"는 방식으로 체류 동기를 준다.
- ❌ `안녕하세요! 오늘은 [주제]에 대해 알아보겠습니다.` → 저품질 신호
- ✅ 검색어에 직접 답하는 문장으로 시작 → 체류 시간 증가

**결론부 원칙**
- 핵심 내용을 3줄 이내로 요약한다.
- 관련 글 내부 링크 삽입 → 체류 시간 연장, C-Rank 긍정 신호.
- "이상으로 ~에 대해 알아봤습니다." 식의 끝맺음은 피한다.

---

### 2-3. 소제목(H태그) 활용

**구글**
- `H1` 태그는 페이지당 **1개만** 사용 (메인 제목).
- `H2` → 주요 단락 구분 (3~5개 권장).
- `H3` → H2의 하위 세부 항목.
- H태그 안에도 자연스럽게 타겟 키워드 또는 LSI(연관) 키워드를 포함한다.
- 구조화된 H태그 계층은 2026년 구글 코어 업데이트 이후 AI 스니펫·검색 결과 선택에도 직접 활용된다.

**네이버 블로그**
- 소제목 기능(에디터의 "제목1~3")을 활용해 단락을 나눈다.
- 소제목마다 연관 키워드나 롱테일 키워드를 자연스럽게 배치한다.
- 소제목 없이 긴 텍스트 덩어리만 있으면 가독성 점수가 낮아진다.

## 3. 키워드 밀도와 배치

### 3-1. 권장 키워드 밀도

| 구분 | 권장 수준 |
|---|---|
| **네이버** | 1,500~2,000자 기준 메인 키워드 **5~6회** 자연 배치 |
| **구글** | 전체 본문의 **1~2%** 수준 (과도한 반복 = 스팸 신호) |

> 키워드 밀도 자체를 목표로 삼지 않는다. 2026년 기준 두 플랫폼 모두 자연스러운 문맥 내 사용을 선호하며, 반복 나열은 오히려 페널티다.

---

### 3-2. 키워드 배치 위치 (우선순위 순)

1. **제목(Title / 포스팅 제목)** — 앞부분에 배치
2. **도입부 첫 100자 이내** — 빠른 주제 신호
3. **H2/H3 소제목** — 구조적 키워드 신호
4. **본문 중반부** — 자연스러운 흐름 속 반복
5. **이미지 alt 텍스트** — 검색 크롤러 대상 보조 신호
6. **결론부** — 키워드로 마무리

---

### 3-3. 롱테일 키워드 전략

- 메인 키워드 외에 **연관 검색어·자동완성 키워드** 2~3개를 본문에 자연스럽게 포함한다.
- 네이버: 검색광고 키워드 도구(`searchad.naver.com`)에서 월간 검색량 **500~5,000** 구간 키워드가 경쟁 강도 대비 효과적이다.
- 구글: 검색 결과 하단의 "관련 검색어"와 자동완성을 활용해 LSI 키워드를 발굴한다.

## 4. 이미지 최적화

### 4-1. 적정 이미지 수

| 플랫폼 | 권장 수 |
|---|---|
| **네이버 블로그** | 상위 노출 1~5위 글의 **평균 이미지 수**에 맞추는 것이 유리 (보통 5~10장 수준). 단, 동일·유사 이미지 반복 삽입은 금지 |
| **구글 블로그** | 내용과 관련 있는 이미지라면 글 **섹션마다 1장** 수준 (2,000자 기준 3~5장)이 가독성과 체류 시간에 긍정적 |

> 이미지 수 자체보다 **이미지의 관련성과 독창성**이 더 중요하다. 스톡 이미지보다 직접 촬영·제작 이미지가 품질 평가에 유리하다.

---

### 4-2. 대표 이미지(썸네일) 규격

| 항목 | 권장 사항 |
|---|---|
| **권장 해상도** | **1200 × 630px** (OG 이미지 표준) |
| **최소 해상도** | 200 × 200px |
| **파일 형식** | JPEG / PNG (웹 최적화 시 WebP 또는 AVIF 권장) |
| **파일 용량** | 1MB 이하 권장 (페이지 속도에 직접 영향) |
| **비율** | 1.91:1 (가로 직사각형) — 카카오·네이버·구글 공유 시 잘림 방지 |

---

### 4-3. Alt 텍스트 (대체 텍스트) 작성 원칙

- 이미지를 **1문장으로 설명**하는 방식으로 작성한다.
- 타겟 키워드를 **자연스럽게 1회** 포함한다.
- ❌ `alt="SEO, 검색엔진최적화, 네이버SEO, 구글SEO, 블로그SEO"` → 키워드 나열 = 스팸 신호
- ✅ `alt="2026년 네이버 SEO 상위 노출 전략 인포그래픽"` → 내용 설명형
- 동일한 alt 텍스트를 여러 이미지에 반복 사용하지 않는다.
- 장식용(배경·구분선) 이미지는 `alt=""` (빈 값)으로 처리한다.

---

### 4-4. 이미지 파일명

- 의미 없는 파일명(`IMG_3047.jpg`, `abc123.png`)은 SEO 기회 낭비다.
- **키워드 포함 설명형 파일명**으로 저장한다.
  - ❌ `image001.jpg`
  - ✅ `naver-seo-guide-2026.jpg`

## 5. 해시태그 활용법

### 5-1. 네이버 블로그 해시태그

- 역할: 검색 알고리즘이 **글의 카테고리·주제를 판단**하는 보조 신호로 활용된다.
- 권장 개수: **3~10개** (핵심 주제와 관련된 것만 선별).
- 지나치게 많은 태그(30개 이상)는 스팸으로 인식될 수 있다.
- **메인 키워드, 서브 키워드, 주제 카테고리** 조합으로 구성한다.
  - 예시: `#해운운임` `#SCFI` `#컨테이너운임` `#물류동향` `#해운뉴스`
- 연관 없는 인기 태그 무분별 사용은 저품질 신호가 된다.

### 5-2. 구글(워드프레스·티스토리 등)

- 구글은 해시태그를 직접적인 랭킹 요소로 사용하지 않는다.
- 다만 태그/카테고리가 **내부 링크 구조** 역할을 하므로 의미 있는 분류가 중요하다.
- 태그 페이지가 너무 많아지면 크롤링 예산이 낭비될 수 있으므로, 유사한 태그는 통합한다.

## 6. 네이버 C-Rank & D.I.A 알고리즘

### 6-1. C-Rank (Creator Rank) — 블로그 출처 신뢰도

> "이 블로그는 믿을 만한가?"를 평가하는 알고리즘. 2016년 도입 후 2026년 현재도 핵심 지표로 작동.

**C-Rank를 높이는 요소**

| 요소 | 설명 |
|---|---|
| **주제 전문성** | 특정 분야 글을 지속 발행하는 블로그가 유리. 2026년 기준 '잡블로그'보다 '전문 주제 블로그'가 훨씬 높게 평가 |
| **발행 꾸준함** | 2주 이상 글이 없으면 블로그 자체 평가 하락. 주 2~3회 이상 유지 권장 |
| **사용자 반응** | 공유 > 댓글·공감 순으로 점수 반영. 체류 시간과 재방문율도 중요한 지표 |
| **고유 콘텐츠** | 직접 경험·후기·분석이 담긴 글. 단순 복사·붙여넣기는 불리 |
| **내부 링크** | 블로그 내 관련 글 연결로 체류 시간 증가 → C-Rank 긍정 신호 |

---

### 6-2. D.I.A (Deep Intent Analysis) — 문서 품질 평가

> "이 글이 사용자의 검색 의도에 얼마나 잘 맞는가?"를 평가. 사용자 경험·후기·구체성을 중시.

**D.I.A가 높게 평가하는 패턴**

| 패턴 | 예시 |
|---|---|
| **구체적 수치 포함** | "대기 시간이 길었다" ❌ → "대기 30분" ✅ |
| **직접 경험·후기 서술** | 단순 정보 나열이 아닌 작성자의 실사용 경험 포함 |
| **검색 의도 직접 충족** | 검색어를 친 사람이 원하는 답을 글 안에서 완결 |
| **체류 시간 유도 구조** | 읽기 쉬운 단락 구분, 소제목, 이미지 혼용 |
| **신뢰도 있는 출처 인용** | 공식 데이터·기관 자료 참조 명시 |
| **독창성** | 기존에 없는 관점·정보·경험 포함 |

---

### 6-3. 2026년 추가 변화 — 스마트블록 & AI 통합

- 2025년부터 네이버 VIEW 섹션은 **스마트블록(Smart Block)** 으로 완전 통합되었다.
- 사용자 검색 의도에 맞게 블록 단위로 콘텐츠를 동적으로 배치하는 구조다.
- 2026년 네이버는 "문서 유형에 관계없이 **신뢰할 수 있는 출처의 문서를 우선 노출**"하는 기술을 공식 적용했다.
- AI 기반으로 콘텐츠의 **구조·정보 밀도·출처 신뢰도**를 종합 평가한다.

---

### 6-4. 구글 EEAT (Experience · Expertise · Authoritativeness · Trustworthiness)

> 2026년 May Core Update 이후 EEAT 신호의 비중이 더욱 강화되었다.

| 요소 | 실천 방법 |
|---|---|
| **Experience (경험)** | 직접 해봤다는 증거(스크린샷, 실측 수치, 직접 사진)를 포함 |
| **Expertise (전문성)** | 작성자 소개·약력 페이지 추가, 전문 용어 정확 사용 |
| **Authoritativeness (권위성)** | 업계 매체 기고·언급, 보도자료, 구체적 데이터 출처 명시 |
| **Trustworthiness (신뢰성)** | 연락처 페이지, HTTPS, 정확한 팩트, AI 사용 여부 투명하게 공개 |

## 7. 어뷰징 판정 기준 & 피해야 할 것

### 7-1. 네이버 저품질(어뷰징) 직접 판정 대상

| 유형 | 상세 내용 |
|---|---|
| **과도한 광고·홍보성 글** | 쿠팡 파트너스 링크, 제휴 마케팅 링크 과다 삽입 |
| **AI 자동 생성 대량 발행** | 하루 수십 개 발행, 비슷한 패턴 반복, 체험 없는 정보 나열 |
| **키워드 스태핑** | 본문·제목에 같은 키워드를 의미 없이 과다 반복 |
| **내용과 무관한 인기 검색어 삽입** | 트렌드 키워드 낚시용 삽입 |
| **복사·붙여넣기 중복 콘텐츠** | 타 사이트 내용 그대로 재발행 |
| **비정상적 방문자 유입 조작** | 자동화 툴로 방문자 수 인위적 증가 |
| **저품질 클리셰 도입/결론부** | "안녕하세요 오늘은~" 시작, "이상으로 알아봤습니다" 결론 |
| **동일·유사 이미지 반복 삽입** | 같은 이미지를 여러 번 넣어 이미지 수 부풀리기 |

---

### 7-2. 구글 스팸/페널티 판정 대상

| 유형 | 상세 내용 |
|---|---|
| **얇은 콘텐츠 (Thin Content)** | 정보가 없거나 너무 짧아 검색 의도를 충족 못 하는 페이지 |
| **키워드 스태핑** | 제목·본문·alt 텍스트에 키워드 나열 |
| **숨겨진 텍스트·링크** | 배경색과 같은 색 텍스트, 숨김 처리된 링크 |
| **중복 콘텐츠** | 동일·유사 페이지 다수 생성 (캐노니컬 태그로 처리 필요) |
| **저품질 AI 생성 대량 콘텐츠** | 사람이 검토 없이 AI 글을 대량 퍼블리시 |
| **비자연적 링크 구매·교환** | 백링크 패키지 구매, 링크 팜(Link Farm) 참여 |
| **스키마 마크업 남용** | 실제 콘텐츠와 다른 내용을 구조화 데이터로 표기 |
| **핵심 업데이트 후 급격한 변경** | 순위 하락 시 패닉 삭제·급조 수정은 오히려 역효과 |

---

### 7-3. 네이버 저품질 판정 시 대응 방법

1. 저품질이 온 날짜의 글을 **비공개** 처리한다.
2. 원상 복귀 전까지 **일상 글·정보성 글**만 올린다.
3. 일괄 삭제보다 **점진적 비공개 → 수정 → 재공개** 순서로 처리한다.
4. 수정 후 재저장 시 네이버·구글이 글을 다시 크롤링한다 (반영에 1~2주 소요).

## 부록: SEO 점검 체크리스트

### 발행 전 체크

- [ ] 메인 키워드가 제목 앞부분에 있는가?
- [ ] 제목이 네이버 기준 35자, 구글 기준 30자 이내인가?
- [ ] 도입부 100자 이내에 키워드가 자연스럽게 등장하는가?
- [ ] H2/H3 소제목으로 단락이 구분되어 있는가?
- [ ] 이미지 alt 텍스트가 내용 설명형으로 작성됐는가?
- [ ] 대표 이미지가 1200×630px 기준에 맞는가?
- [ ] 내용과 무관한 키워드·해시태그가 없는가?
- [ ] 직접 경험·수치·출처가 포함됐는가?
- [ ] "안녕하세요~", "이상으로~" 클리셰가 없는가?
- [ ] 관련 글 내부 링크가 1~3개 포함됐는가?

- [ ] 구글 서치콘솔에 색인 요청을 보냈는가?
- [ ] 네이버 서치어드바이저에서 품질 이슈가 없는가?
- [ ] 체류 시간이 경쟁 글 대비 짧지 않은가?
- [ ] 이미지 로딩 속도(WebPageTest, PageSpeed Insights)를 확인했는가?
