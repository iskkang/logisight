# 해운·물류 전문기자 문체 스타일 가이드

> 이 파일 하나만으로 동일한 톤·문체의 기사를 재현할 수 있도록 작성된 스타일 가이드입니다.

---

## 1. 제목 패턴

### 구조 원칙
- **메인 제목**: 핵심 팩트 + 수치/결과를 압축해서 명사형으로 끝낸다.
- **부제(서브헤드)**: 메인 제목에서 생략된 맥락·배경·비교를 보완한다. 메인과 짝을 이뤄야 한다.
- 두 줄이 세트다. 메인 → 부제 순서로 반드시 붙인다.

### 제목 어법
- 동사 종결형이 아닌 **명사형·형용사형 종결**이 원칙이다.
  - ✅ `중동행 컨테이너운임 4300弗 돌파…사상최고치`
  - ✅ `LX판토스·태웅로직스 상승세 vs CJ대한통운 하락곡선`
  - ❌ `중동 컨테이너 운임이 사상 최고치를 기록했습니다`
- **한자 숫자·기호**를 적극 혼용한다: `弗`(달러), `億`(억), `%`(%), `↑↓`(증감).
  - 예: `3억弗`, `31%↑`, `4300弗`
- **줄임말·약어**를 자연스럽게 쓴다: `컨운임`, `소석률`, `포워더`, `TEU`, `FEU`.
- 영문 사명은 원어 그대로: `ONE`, `NYK`, `MOL`, `DSV`, `DHL`.
- 숫자는 아라비아 숫자로 쓰고 단위를 붙인다: `주10회`, `11개월`, `50위권`.
- `…`(말줄임표 3점)은 제목 안에서 전환·강조 용도로 쓴다: `4300弗 돌파…사상최고치`.
- `vs`는 대비 구도를 만들 때 영문 그대로 쓴다.
- `·`(가운뎃점)은 동급 열거에 사용: `LX판토스·태웅로직스`.

### 부제 패턴 예시
| 메인 제목 | 부제 역할 |
|---|---|
| 수치·결과 선언 | 원인·배경 설명 |
| 기업명 + 방향성 | 시장 맥락 보완 |
| 기관 발표 사실 | 구체 수치·달성 내용 |

## 2. 소제목(중간 제목) 패턴

- 긴 기사는 **2~3개의 소제목**으로 단락을 구분한다.
- 소제목도 제목과 동일하게 **명사형·요약형**으로 끝낸다.
  - 예: `'벌크선사업 부진' 3대 해운사, 영업익 두자릿수 감소`
  - 예: `中포워더 비중 확대…DSV는 쉥커 인수효과 누려`
  - 예: `3대 해운사, 올해 영업익 전망 희비`
- 소제목 안에서도 핵심 키워드(기업명, 수치, 방향)를 먼저 노출한다.
- 따옴표(`' '`)로 핵심어를 감싸는 패턴을 간헐적으로 사용한다.
  - 예: `'벌크선사업 부진' 3대 해운사`
  - 예: `'단순함이 주는 대담함'이 콘셉트`

## 3. 기사 구성 순서

### 전형적인 3단 구조

```
① 도입부 (1~2문장)
   → 핵심 결론/사실을 선언한다. 배경 설명 없이 팩트 직격.

② 근거 전개 (주요 단락)
   → 수치·출처·비교 데이터를 순서대로 나열한다.
   → 소제목으로 하위 주제를 분리한다.

③ 인용구 마무리 (선택)
   → 기관 관계자·임원의 공식 코멘트로 끝맺는다.
   → 전망·방향성을 담는다.
```

### 도입부 패턴 (리드문)
- 첫 문장에서 **주어 + 핵심 성과/사실**을 바로 제시한다.
- "~을 기록했다", "~을 밝혔다", "~을 넘어섰다" 형태.
- 배경·원인은 두 번째 문장 이후로 미룬다.

> 예: *"중국-중동 컨테이너 운임이 사상 최고치를 기록했다."*
> 예: *"한국해운조합(KSA)은 5월22일 기준 선주배상책임공제(P&I) 가입 선박 수가 전년 대비 31% 증가하고, 연간 공제료는 5% 늘어났다고 밝혔다."*

### 마무리 패턴
- 관계자 인용구로 끝나는 경우가 가장 많다.
- 인용 뒤 추가 코멘트로 전망·계획을 한 줄 더 붙이는 이중 마무리도 자주 쓴다.
- "~이라고 말했다", "~이라고 밝혔다", "~이라고 덧붙였다" 순서로 인용을 쌓는다.

## 4. 말투 & 문장 종결 어미

### 기본 어미
| 용도 | 어미 형태 | 예 |
|---|---|---|
| 사실 서술 | `~을 기록했다` | `4306달러를 기록했다` |
| 발표·공식 | `~을 밝혔다` | `31% 증가했다고 밝혔다` |
| 수치 집계 | `~로 집계됐다` | `1292만7000TEU로 집계됐다` |
| 예측·전망 | `~로 점쳤다` / `~로 내다봤다` | `5억달러를 거둘 것으로 점쳤다` |
| 인용 마무리 | `~고 말했다` / `~고 밝혔다` | `~이라고 말했다` |
| 추가 설명 | `~이라고 덧붙였다` | `10월 이후도 검토할 것이라고 덧붙였다` |
| 이유·원인 | `~인 셈이다` / `~이 영향을 미쳤다` | `중동 전쟁이 영향을 미쳤다` |

### 사용하지 않는 어미
- `~입니다`, `~합니다` → 문어체 기사에선 절대 안 씀.
- `~했습니다`, `~됩니다` → 동일.
- `~라고 한다` (전문형 추측) → 최대한 피한다. 출처를 명시하고 직접 서술.

## 5. 문장 호흡

### 길이
- 한 문장은 **40~80자** 내외가 기본. 수치가 많은 문장은 90자까지 늘어나도 허용.
- 수치가 두 개 이상 나오면 **쉼표(,) 또는 공백**으로 구분해 나열한다.
  - 예: *"영업이익 3억1000만달러(약 4600억원), 순이익 3억3800만달러(약 5000억원)를 각각 냈다."*
- **"각각"** 은 두 수치를 동시 나열할 때 필수 단어다.
  - 예: `영업이익과 순이익 모두 92% 감소했다`
  - 예: `각각 9위 39위 49위에 올랐다`

### 수치 표기 관행
- 원화 환산은 괄호 안에 병기: `3억1000만달러(약 4600억원)`
- 증감률은 수치 뒤 바로: `전년 대비 31% 증가`, `전년 대비 34% 역신장`
- 감소 표현은 **"역신장"**, **"후퇴"**, **"감소"**, **"줄었다"** 를 번갈아 써서 단조로움을 피한다.
- 증가 표현도 마찬가지: **"늘었다"**, **"신장했다"**, **"일궜다"**, **"기록했다"** 를 교차.

### 비교 표현 패턴
- `전년 [수치] 대비 [증감률] [증감한] [수치]` 구조가 기본이다.
  - 예: *"전년 1275만TEU 대비 1% 늘어난 1292만7000TEU를 기록했다."*
- 기간 비교 시 **"1년 전"** 과 **"전년"** 을 번갈아 쓴다.
- "전분기(3분기)에 비해" 처럼 **소괄호로 시기 명시**를 병기한다.

## 6. 인용 처리 방식

### 직접 인용
- 큰따옴표(`" "`) 안에 담고, 뒤에 `~고 말했다` / `~고 밝혔다`로 마무리.
- 인용자 표기는 이름 + 직함 순서: `이채익 조합 이사장은`
- 선사·기관 이름이 인용자일 때: `선사 측은`, `조합 측은`, `선사 관계자는`

### 인용 연결
- 두 개의 코멘트를 이어받을 때: 첫 인용 `~이라고 말했다.` → `이어 "~"이라고 덧붙였다.`
- 이 패턴으로 마무리를 자연스럽게 늘릴 수 있다.

### 괄호 참고 주석
- 통계 출처는 문장 끝에 괄호로 처리: `(해사물류통계 '항목명' 참고)`
- 독자에게 추가 데이터 소스를 안내하는 동시에 기사 신뢰도를 높인다.

## 7. 단어 선택 & 어휘 특징

### 업계 전문용어 (그대로 쓴다)
`소석률`, `TEU`, `FEU`, `케이프사이즈`, `파나막스`, `톤마일`, `포워더`, `P&I보험`, `공제료`, `선주배상책임공제`, `신조선`, `지정학적 리스크`, `구간별 운임`, `운항선박`, `선교(브리지)`

### 한자어 선호 표현
| 구어체 | 기사체 |
|---|---|
| 내려갔다 | 역신장했다 / 후퇴했다 |
| 올라갔다 | 신장했다 / 증대했다 |
| 돈을 벌었다 | 실적을 일궜다 |
| 예상된다 | 전망했다 / 점쳤다 / 내다봤다 |
| 이유는 | ~이 영향을 미쳤다 / ~이 요인으로 꼽혔다 |

### 대조·전환 접속어
- **"반면"** → 수치가 반대 방향일 때 단락 첫머리에 단독 사용.
  - 예: *"반면, 남아프리카(더반)행 운임은 TEU당 전주 2167달러에서 1% 내린 2146달러에 머물며 나 홀로 하락세를 보였다."*
- **"이 밖에"** → 부가 항목 열거 시 단락 시작.
- **"이어"** → 추가 인용이나 후속 정보 연결.
- **"한편"** → 주제가 살짝 바뀔 때 전환.
- **"가운데"** → 배경 상황 제시: *"이러한 가운데 ~은 ~을 기록했다."*

### 강조 표현
- **"나 홀로 하락세"** → 다수가 상승할 때 예외 항목을 부각.
- **"두 자릿수"** → 10% 이상 증감을 압축 표현.
- **"희비(가 엇갈렸다)"** → 기업별·항로별 명암이 다를 때.
- **"흑자 전환"**, **"반등"** → 손실→이익, 하락→상승 전환 시.

## 8. 숫자·단위 표기 규칙

| 항목 | 규칙 | 예 |
|---|---|---|
| 달러 | 아라비아 숫자 + 달러 or 弗 | `3억1000만달러`, `3억弗` |
| 원화 | 괄호 병기, "약" 앞에 붙임 | `(약 4600억원)` |
| 엔화 | 숫자 + 억엔 | `1386억엔(약 1조3000억원)` |
| 증감률 | 숫자 + % + 공백 없이 | `31% 증가`, `34% 역신장` |
| 컨테이너 | TEU / FEU | `1292만7000TEU`, `FEU당 3154달러` |
| 빈도·횟수 | 숫자 + 단위 붙여 씀 | `주10회`, `3주 연속` |
| 순위 | 숫자 + 위 | `9위`, `50위권` |
| 퍼센트포인트 | `%p` 또는 `%포인트(p)` | `8%p`, `1%p(포인트) 상승` |

## 9. 문단 구성 원칙

1. **한 문단 = 하나의 주제** 또는 하나의 항목 그룹.
2. 수치 나열이 많아지면 **쉼표 스트링** 방식으로 압축한다.
   - 예: *"북유럽행 1905달러, 지중해행 3207달러, 동아프리카(몸바사)행 2708달러, 호주(멜버른)행 1398달러를 각각 기록했다."*
3. 공백 줄 없이 **문단을 붙여** 쓴다. 소제목으로만 단락을 나눈다.
4. 마지막 문단은 반드시 **전망 또는 인용**으로 끝낸다.

## 10. 전체 톤 요약

| 속성 | 설명 |
|---|---|
| **문체** | 건조한 사실 위주 보도문. 감정·주관 배제. |
| **시제** | 과거형 위주 (`~했다`, `~됐다`). 전망은 미래형 (`~할 것으로 전망했다`). |
| **인칭** | 3인칭. `~사 측은`, `~조합은`, `선사 관계자는`. |
| **권위 근거** | 출처 명시 의무: 기관명·보고서명·날짜. |
| **반복 회피** | 동의어 교차로 단조로움 방지 (감소↔역신장↔하락, 증가↔신장↔성장). |
| **밀도** | 고밀도. 수치를 빽빽하게 쓰되 문장이 터지지 않도록 쉼표로 조절. |
