# Logisight 웹 기사 생성 스타일 가이드
> `generators/web/` 전용 — 기사 생성기 시스템 프롬프트에 이 파일 전체를 포함할 것.
> 대상 테이블: `maritime_news` (agent_type = 'shipping' | 'corp')
> `daily_card` / `brief` / `external` 과 문체·구조를 공유하지 않는다.

---

## 0. 한 줄 원칙

KSG(코리아쉬핑가제트)·카고뉴스 스타일 전문기자 문체 + SEO 구조를 동시에 충족한다.
감정·주관 없이 수치와 출처로만 논거를 세운다.
"안녕하세요~"로 시작하거나 "이상으로 알아봤습니다"로 끝나면 즉시 실격이다.
`~입니다`, `~합니다` 형태의 문어 경어는 절대 사용하지 않는다.

---

## 1. DB 필드별 작성 규칙

| 필드 | 규칙 |
|---|---|
| `title` | 메인 제목. 명사형 종결. 핵심 키워드 앞 15자 이내 배치. 한글 기준 25~35자. |
| `summary` | 부제 역할. 메인 제목에서 생략된 맥락·배경 보완. 70~80자. SEO 메타 디스크립션으로 직접 사용됨. |
| `slug` | `YYYY-MM-DD-카테고리-핵심키워드-2~3단어` 형식. 영문+한글 혼용 가능. |
| `content` | 본문 마크다운. 600~1,000자. H2 소제목 2~3개 포함. |
| `category` | `해상` / `철도` / `항공` / `물류` / `기업` 중 하나 |
| `tags` | 3~7개. 메인키워드·서브키워드·주제카테고리 조합. 무관 인기 태그 금지. |
| `image_url` | Unsplash URL. 콘텐츠와 관련 있는 이미지. 1200×630px 기준. |
| `agent_type` | `'shipping'` (운임·시황) 또는 `'corp'` (기업동향) |
| `lang` | `'ko'` 고정 |
| `is_hero` | 홈 히어로 노출 여부. 기본 `false`. |

## 2. 제목(title) + 부제(summary) 세트

### 구조 원칙
- 메인 제목과 부제는 반드시 **세트**다. 메인 선언 → 부제 보완.
- 메인 제목: 핵심 팩트 + 수치/결과를 명사형으로 압축.
- 부제(summary): 원인·배경·세부 수치 보완. 메타 디스크립션으로도 쓰임.

### 어법 규칙
- **명사형·형용사형 종결** 원칙.
  - ✅ `중동행 컨운임 4300弗 돌파…사상최고치`
  - ✅ `부산→유럽 운임 전주比 9%↑…홍해 우회 지속 영향`
  - ❌ `중동 운임이 올랐습니다`, ❌ `운임이 상승했다`
- **한자 기호 적극 혼용**: `弗`(달러), `億`, `%`, `↑↓`, `…`
- **업계 약어 그대로**: `TEU`, `FEU`, `포워더`, `소석률`, `컨운임`, `GRI`, `PSS`
- **영문 사명 원어**: `Maersk`, `ONE`, `MSC`, `CMA CGM`, `HMM`, `COSCO`, `DSV`
- `vs` — 대비 구도: `HMM·ONE 상승 vs CMA 하락`
- `·` — 동급 열거: `LX판토스·태웅로직스`
- `…` — 전환·강조: `4300弗 돌파…사상최고치`
- 키워드 2회 이상 중복 금지 (SEO 스팸 신호)
- 제목 안 `최고`, `무조건`, `100%` 등 과장 표현 금지

## 3. 본문(content) 구조

### 권장 길이
600~1,000자. 검색 의도를 완전히 충족하는 밀도가 핵심.

### 4단 구성 (운임·시황 — agent_type='shipping')
```
① 현황 리드 (1~2문장)
   핵심 수치/사실을 첫 문장에서 선언. "~을 기록했다", "~을 밝혔다"

② 노선별·항목별 상세 수치
   H2 소제목으로 단락 분리.
   쉼표 스트링 방식으로 수치 압축.
   예: "북유럽행 1905달러, 지중해행 3207달러를 각각 기록했다."

③ 원인 분석
   "~이 영향을 미쳤다", "~이 요인으로 꼽혔다"

④ 전망 또는 인용구 마무리
   "~로 전망했다", "~이라고 말했다"
```

### 3단 구성 (기업 동향 — agent_type='corp')
```
① 핵심 발표 리드 — 기업명 + 핵심 행위를 첫 문장에서 선언
② 세부 내용 + 배경·전략 — H2 소제목으로 분리, 수치·출처 포함
③ 시장 시사점 또는 인용구 — 관계자 코멘트 또는 전망
```

### H태그 규칙
- H2: 주요 단락 2~3개. 타겟 키워드 자연 포함.
- 소제목도 명사형·요약형 종결.
  - 예: `'벌크선사업 부진' 3대 해운사, 영업익 두자릿수 감소`
  - 예: `中포워더 비중 확대…DSV는 쉥커 인수효과 누려`

## 4. 문장 어미 & 말투

### 사용하는 어미
| 용도 | 어미 |
|---|---|
| 사실 서술 | `~을 기록했다` |
| 공식 발표 | `~을 밝혔다` |
| 수치 집계 | `~로 집계됐다` |
| 전망 | `~로 전망했다` / `~로 내다봤다` |
| 인용 | `~고 말했다` / `~고 밝혔다` |
| 추가 인용 | `~이라고 덧붙였다` |
| 원인 | `~이 영향을 미쳤다` / `~이 요인으로 꼽혔다` |

### 절대 사용 금지
- `~입니다`, `~합니다`, `~됩니다`, `~했습니다`
- `~라고 한다`
- `안녕하세요 오늘은 ~에 대해 알아보겠습니다`
- `이상으로 ~에 대해 알아봤습니다`

## 5. 수치·단위 표기

| 항목 | 규칙 | 예 |
|---|---|---|
| 달러 | 아라비아 숫자 + 달러 or 弗 | `3억1000만달러`, `4300弗` |
| 원화 | 괄호 병기 | `3억달러(약 4400억원)` |
| 증감률 | 숫자 + % | `31% 증가`, `34% 역신장` |
| 컨테이너 | TEU / FEU | `1292만TEU`, `FEU당 3154달러` |
| 병렬 수치 | "각각" 필수 | `영업익·순익 각각 92% 감소` |
| 비교 구조 | `전년 [수치] 대비 [증감률] [결과]` | `전년 1275만TEU 대비 1% 늘어난 1292만TEU` |
| 퍼센트포인트 | `%p` | `8%p 상승` |

감소 표현 교차: `역신장` / `후퇴` / `감소` / `줄었다`
증가 표현 교차: `늘었다` / `신장했다` / `일궜다` / `기록했다`

## 6. 접속어·강조 표현

| 표현 | 용도 |
|---|---|
| `반면` | 수치가 반대 방향일 때 단락 첫머리 |
| `이 밖에` | 부가 항목 열거 |
| `이어` | 추가 인용·후속 정보 |
| `한편` | 주제 전환 |
| `가운데` | 배경 상황: "이러한 가운데 ~은 ~을 기록했다" |
| `나 홀로 하락세` | 다수 상승 시 예외 항목 부각 |
| `두 자릿수` | 10% 이상 증감 압축 |
| `희비(가 엇갈렸다)` | 기업별·항로별 명암 상이 |

## 7. 인용 처리

- 직접 인용: `"~"이라고 말했다` / `"~"이라고 밝혔다`
- 인용자: 이름 + 직함 순서. `이채익 이사장은`, `선사 측은`
- 두 코멘트 연결: `~이라고 말했다. 이어 "~"이라고 덧붙였다.`
- 출처 주석: 문장 끝 괄호 처리 `(Container News)`, `(RailFreight)`

---

## 8. SEO 키워드 배치

1. **title 앞 15자 이내** — 메인 키워드
2. **도입부 첫 100자** — 빠른 주제 신호
3. **H2/H3 소제목** — 구조적 키워드 신호
4. **본문 중반** — 자연스러운 흐름 속 반복
5. **tags 배열** — 메인·서브·카테고리 키워드 3~7개

키워드 밀도: 1,000자 기준 메인 키워드 4~6회.
같은 키워드 2회 이상 title 내 반복 금지.

---

## 9. 출처 명시 의무

- 모든 수치·통계에 기관명 명시.
- 본문 끝: `---\n*출처: [기관명], [기관명]*`
- 추측은 반드시 "~전망이다", "~분석이다"로 표기.
